# 🩺 VisionCare AI — Explainable Diabetic Retinopathy Screening

### Rural DR Screening Support

VisionCare AI is a prototype designed to support diabetic retinopathy screening by analyzing retinal fundus images and providing an easy-to-understand screening result for trained health workers.

## 🎯 Objective

The project aims to support early screening and referral by helping identify retinal images that may require further examination by an eye-care professional.

## 💡 Key Features

* 🖼️ Fundus image upload
* 🔍 AI-assisted diabetic retinopathy screening
* 📊 Explainable screening results
* 🚦 Screening prioritisation
* 👨‍⚕️ Referral support
* 🌐 Simple and user-friendly interface
* 🏥 Designed with rural screening scenarios in mind

## 🔄 How It Works

**Upload Image → Screen → Explain → Prioritise → Refer**

1. Upload a retinal fundus image.
2. The system analyzes the image.
3. A screening result is generated.
4. The result is presented in an understandable format.
5. Cases requiring further examination can be referred to an eye-care professional.

## 🛠️ Technologies Used

* Python
* Streamlit
* Computer Vision
* Machine Learning / AI
* HTML & CSS

## 👩‍⚕️ Intended Use

This project is a **prototype for screening support** and is intended for demonstration and educational purposes.

It is **not a replacement for professional medical diagnosis**. Final diagnosis and treatment decisions should be made by qualified eye-care professionals.

## 🌍 Social Impact

The project explores how AI-assisted screening could help support early identification and referral, particularly in settings where access to specialized eye-care services may be limited.
